In OBE, the three learning domains and their commonly used levels are:

## 1. Cognitive Domain (Knowledge & Thinking) — Bloom's Taxonomy

| Level | Name       |
| ----- | ---------- |
| C1    | Remember   |
| C2    | Understand |
| C3    | Apply      |
| C4    | Analyze    |
| C5    | Evaluate   |
| C6    | Create     |

Examples of verbs:

* C1: Define, List, Recall
* C2: Explain, Describe, Summarize
* C3: Apply, Use, Implement
* C4: Analyze, Differentiate, Compare
* C5: Evaluate, Justify, Critique
* C6: Design, Develop, Create

---

## 2. Affective Domain (Attitudes, Values & Behavior) — Krathwohl's Taxonomy

| Level | Name           |
| ----- | -------------- |
| A1    | Receiving      |
| A2    | Responding     |
| A3    | Valuing        |
| A4    | Organizing     |
| A5    | Characterizing |

Examples of verbs:

* A1: Listen, Attend, Observe
* A2: Participate, Discuss, Answer
* A3: Support, Demonstrate, Respect
* A4: Integrate, Organize, Prioritize
* A5: Practice, Influence, Act Consistently

---

## 3. Psychomotor Domain (Practical & Physical Skills) — Simpson's Taxonomy

| Level | Name                   |
| ----- | ---------------------- |
| P1    | Perception             |
| P2    | Set                    |
| P3    | Guided Response        |
| P4    | Mechanism              |
| P5    | Complex Overt Response |
| P6    | Adaptation             |
| P7    | Origination            |

Examples of verbs:

* P1: Detect, Identify, Recognize
* P2: Prepare, Position, Arrange
* P3: Perform, Follow, Practice
* P4: Operate, Manipulate, Execute
* P5: Calibrate, Assemble, Demonstrate
* P6: Modify, Adapt, Improve
* P7: Design, Construct, Invent

---

### Summary

| Domain      | Levels                             |
| ----------- | ---------------------------------- |
| Cognitive   | C1–C6 (Remember → Create)          |
| Affective   | A1–A5 (Receiving → Characterizing) |
| Psychomotor | P1–P7 (Perception → Origination)   |

These are the most commonly used taxonomies in OBE and accreditation systems for engineering, computing, and other academic programs.
